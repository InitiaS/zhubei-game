# 贮贝 · 滇人采贝

云南江川李家山「驯马场面铜贮贝器」（西汉）主题的现场互动小游戏：黄金矿工玩法，
滇人采贝入器，看谁所贮最多。

单文件交付：`index.html` —— 零外部依赖、零构建，双击即可运行。

> 两千年前，滇人把来自印度洋的贝壳盛进青铜重器；今天，你把它们一枚枚钩进同一只贮贝器。

西汉滇国以海贝为币，铸贮贝器贮藏，器盖铸十人七马驯马之景。游戏取「采贝入器」为玩法，
贮满六千为「满器」，七骑绕场以应器盖群雕。海贝经蜀身毒道自印度洋而来——一件青铜器，
见证西南边疆早在两千年前已与世界相连。

## 玩法

| 模式 | 说明 |
| --- | --- |
| 一分钟极速拾贝 | 60 秒计时，冲高所贮枚数，满分即「满器」6000 枚 |
| 贡贝无穷挑战赛 | 逐关加额，不足则止；手柄 B 键可暂停 / 收钩结算 |

- 鼠标点按或空格放钩；手柄 **A** 放钩、**B** 暂停、**X** 断绳
- 铜鼓最重而值低，石髓珠最小而最贵；重物可断绳弃之
- 连中不空 **8 次**即派出骑马滇人抛贝补货（不递增、无冷却）
- 场上随机一种贝货被「悬赏」**外发光**标记：钩满 **3 枚加 500**，超时未足则标记消失
- 一分钟局内贮满 6000 枚：十人七马绕场大庆，并另题「满器榜」
- 榜册各留 15 席，写入浏览器本地存储；三分钟无人操作自动进入演示模式（不计榜）
- 赛场上就是**这件文物本身**：器身由实拍照片抠出内联进单文件，非手绘
- 右下角 **⛶** 或按 **F** 进入全屏，按 16:9 屏等比放大，画面不拉伸
- 舞台随窗口自适应：浏览器最大化 / 拖动窗口 / 切全屏都会重算尺寸，比例恒定 900:620；屏幕变大时场内文字按钮同步等比放大，不会「越大字越小」
- 结算页光标默认停在「再来一局」，手柄按 A 直接开下一局
- 开场物资按设计量的 **75%** 投放（第 1 关 33 → 25 件），场地不挤，也给马队补货留出空间

## 本地运行

```bash
git clone https://github.com/InitiaS/zhubei-game.git
cd zhubei-game
open index.html          # macOS
```

如需在本地起服务（便于移动设备同局域网测试）：

```bash
python3 -m http.server 8000
# 浏览器打开 http://<本机IP>:8000/index.html
```
