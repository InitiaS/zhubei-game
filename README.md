# 贮贝 · 滇人采贝

云南江川李家山「驯马场面铜贮贝器」（西汉）主题的现场互动小游戏：黄金矿工玩法，
滇人采贝入器，看谁所贮最多。

单文件交付：`index.html` —— 零外部依赖、零构建，双击即可运行。

## 在线试玩

GitHub Pages：<https://InitiaS.github.io/zhubei-game/>

## 玩法

| 模式 | 说明 |
| --- | --- |
| 一分钟极速拾贝 | 60 秒计时，冲高所贮枚数，满分即「满器」6000 枚 |
| 贡贝无穷挑战赛 | 逐关加额，不足则止；手柄 B 键可暂停 / 收钩结算 |

- 鼠标点按或空格放钩；手柄 **A** 放钩、**B** 暂停、**X** 断绳
- 铜鼓最重而值低，石髓珠最小而最贵；重物可断绳弃之
- 连中不空 10 次（其后 12 / 14…递增）派出骑马滇人抛贝补货
- 一分钟局内贮满 6000 枚：十人七马绕场大庆，并另题「满器榜」
- 榜册各留 15 席，写入浏览器本地存储；三分钟无人操作自动进入演示模式（不计榜）

## 本地运行

```bash
git clone https://github.com/InitiaS/zhubei-game.git
cd zhubei-game
open index.html          # macOS
```

如需在本地起服务（便于移动设备同局域网测试）：

```bash
python3 -m http.server 8000
# 浏览器打开 http://<本机IP>:8000/index.html
```
